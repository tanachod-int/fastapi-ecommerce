# FastAPI E-Commerce API

> Production-ready REST API built with Python, FastAPI, and PostgreSQL.

🚧 **Work in Progress** — Full documentation coming soon.

## Tech Stack

- **Runtime:** Python 3.11+ / FastAPI / Uvicorn
- **Database:** PostgreSQL (Neon) / SQLAlchemy 2.0 async
- **Cache:** Redis (Upstash)
- **Auth:** JWT + RBAC
- **Deploy:** Render / Docker
